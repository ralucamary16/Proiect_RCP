# Portofoliu digital - Petrișor Raluca-Maria

Acesta este un site de portofoliu digital pregătit pentru GitHub Pages.

## Fișiere incluse

- `index.html` - pagina principală
- `style.css` - designul site-ului
- `script.js` - meniul mobil și butonul de întoarcere sus

## Ce trebuie să modifici tu

1. În `index.html`, caută textul `Adaugă aici poza ta`.
   - Poți adăuga poza ta manual.
   - Creează un folder numit `imagini`.
   - Pune poza în folder, de exemplu `poza-mea.jpg`.
   - Înlocuiește blocul cu placeholder cu:
     `<img src="imagini/poza-mea.jpg" alt="Poză Petrișor Raluca-Maria" class="profile-photo">`

2. În `index.html`, caută:
   - `adaugă aici adresa ta de email`
   - `adaugă aici linkul profilului tău`
   și completează cu datele tale.

3. După ce îți faci cont de GitHub, poți încărca aceste fișiere într-un repository.

## Pași simpli pentru GitHub Pages

1. Intră pe github.com și creează cont.
2. Creează un repository nou, de exemplu `portofoliu-digital`.
3. Încarcă fișierele `index.html`, `style.css`, `script.js`.
4. Intră în repository la Settings.
5. Mergi la Pages.
6. La Branch alege `main`.
7. Apasă Save.
8. După câteva minute, GitHub îți va genera linkul site-ului.

## Observație

Site-ul este responsive, deci se vede bine și pe telefon, și pe laptop.
